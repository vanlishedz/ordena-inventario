# Inventario Ordenado

Mod de cliente para Minecraft Java **1.21.11** con Fabric, creado por
**vanlishedz**.

## Descarga e instalacion

Descarga el JAR oficial más reciente desde la pestaña **Releases** de este
repositorio. Instala Fabric Loader para Minecraft 1.21.11 y Fabric API; luego
copia `ordena-inventario-<version>.jar` a la carpeta `mods` de tu instancia.
Mod Menu es opcional.

Los atajos predeterminados son F7 para ordenar el inventario del jugador y F8
para ordenar el contenido de cofres, barriles, cofres de ender y cajas de
shulker. Puedes cambiarlos en **Opciones > Controles > Inventario Ordenado**.

Para funciones, configuración y ayuda, consulta este README y las notas de la
release. Al informar un error, indica la versión del mod, Minecraft,
Fabric Loader, otros mods relevantes y pasos para reproducirlo. No adjuntes
tokens, contraseñas ni datos personales.

## Integridad

En cada release se publicará el SHA-256 del JAR. Comprueba que el archivo
descargado coincide antes de instalarlo.
